# Workshop version history

[← Workshop](../README.md)

Workshop uses **one maintained product identity**. This is a release and milestone index, not a folder containing a complete duplicate source tree for every version.

| Milestone | Scope | Verification | Status |
| --- | --- | --- | --- |
| Early glass-lab prototype | Phone-friendly display and browser-based simulated cards | Local web/simulator experiments | Experimental |
| Workshop Pocket v0.5 experiments | Capture, browser extension direction, iPhone PWA and HUD concepts | Work-in-progress test fixtures and previews | Private R&D |
| Workshop Pocket v0.6 development | Shared SDK, browser/phone integration and glasses adapter workstreams | Independent working branches; unified acceptance not yet established | Integration pending |

**No numbered public release is claimed by this table.** A public release will appear here only when a reproducible, independently tested artifact and reviewed source/tag are published. Unfinished worktrees and historical experiments are preserved privately; do not confuse directory names with shipped releases.

The source of truth for versions should be Git tags, a changelog, and release manifests. The active source tree should stay in one place.
